1. 连续周期信号的傅里叶级数 (Fourier Series, FS)

公式：

\[x(t) = \sum_{k=-\infty}^{\infty} X[k] e^{j k \omega_{0} t}\] \[X[k] = \frac{1}{T} \int_{T} x(t) e^{-j k \omega_{0} t} d t\]

其中 $\omega_{0} = \frac{2\pi}{T}$ 为基角频率。

说明：

  • 限制： 需满足狄里赫利 (Dirichlet) 条件。
  • 性质： 周期信号的频谱是离散的，且 $X[k] \neq 0$ 仅在 $\omega = k \omega_{0}$ 处。

2. 连续非周期信号的傅里叶变换 (Fourier Transform, FT)

公式：

\[X(j \omega) = \int_{-\infty}^{\infty} x(t) e^{-j \omega t} d t\] \[x(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(j \omega) e^{j \omega t} d \omega\]

说明：

  • 限制： 信号需满足绝对可积。
  • 性质： 连续非周期信号的频谱是连续的。

3. 单位冲激函数 (Unit Impulse Function)

用于联系连续周期信号和非周期信号的频谱。

定义：

\[\delta(t) = \lim_{\tau \to 0} \frac{1}{\tau} \text{rect}(\frac{t}{\tau})\]

性质：

\[\int_{-\infty}^{\infty} \delta(t) d t = 1\]

周期冲激串的傅里叶级数：

\[\sum_{k=-\infty}^{\infty} e^{j k \omega_{0} t} = T \sum_{m=-\infty}^{\infty} \delta(t - m T)\]

4. 一般周期信号的广义傅里叶变换 (Generalized Fourier Transform, FT)

公式：

\[X(j \omega) = \sum_{k=-\infty}^{\infty} X[k] 2\pi \delta(\omega - k \omega_{0})\]

说明：

  • $X[k]$ 是信号 $x(t)$ 的傅里叶级数系数。
  • 性质： 频谱由无穷多个冲激函数组成，冲激间隔为 $\omega_{0}$。

时域采样 (Sampling)

用于连接连续域与离散域。

采样信号： \(x_{\delta}(t) = \sum_{n=-\infty}^{\infty} x(n T_{s}) \delta(t - n T_{s})\)

频谱： \(X_{\delta}(j \omega) = \frac{1}{T_{s}} \sum_{k=-\infty}^{\infty} X(j (\omega - k \omega_{s}))\)

5. 离散周期信号的傅里叶级数 (Discrete-Time Fourier Series, DTFS)

公式：

\[x[n] = \sum_{k=0}^{N-1} X[k] e^{j \frac{2\pi}{N} k n}\] \[X[k] = \frac{1}{N} \sum_{n=0}^{N-1} x[n] e^{-j \frac{2\pi}{N} k n}\]

说明：

  • $x[n]$ 是以 $N$ 为周期的离散信号。
  • $X[k]$ 也是周期为 $N$ 的离散序列。

时域与频域关系：

  • 时域周期 $\leftrightarrow$ 频域离散
  • 时域离散 $\leftrightarrow$ 频域周期

6. 离散傅里叶变换 (Discrete Fourier Transform, DFT)

公式：

DFT (正变换): \(X[k] = \sum_{n=0}^{N-1} x[n] W_{N}^{k n}, \quad k = 0, 1, \dots, N-1\)

IDFT (逆变换): \(x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k] W_{N}^{-k n}, \quad n = 0, 1, \dots, N-1\)

说明：

  • 其中 $W_{N} = e^{-j \frac{2\pi}{N}}$ 称为旋转因子 (twiddle factor)。
  • 关系： DFT 是 DTFS 系数的 $N$ 点表示。
  • 注意： 离散信号的连续频谱是周期函数，而 DFT 只是对该连续频谱进行了周期性采样，两者在形式上非常相似。

7. DFT 核函数 (DFT Kernel Function)

正交性：

\[W_{N}^{k n} \left(= e^{-j \frac{2\pi}{N} k n}\right) : \quad \sum_{n=0}^{N-1} W_{N}^{k n} W_{N}^{-m n} = \sum_{n=0}^{N-1} e^{-j \frac{2\pi}{N} (k-m) n} = \begin{cases} N & k=m \\ 0 & k \neq m \end{cases}\]
